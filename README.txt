ContentFlow Reframe V4

Incluye la interfaz oscura aprobada y una vista previa en vivo dentro de “Ajustar encuadre”.
Los controles horizontal y vertical empiezan en 0 para cada video nuevo y el botón Restablecer devuelve al encuadre inicial.
La vista previa usa el video seleccionado localmente; no genera un MP4 durante los ajustes. El recorte se aplica al crear el video y la misma zona útil se usa para la salida elegida.

Publicación: sube el contenido de esta carpeta a tu repositorio de GitHub Pages. Conserva una copia de la versión anterior hasta probar la nueva.
Nota: JavaScript y la estructura del ZIP se verificaron; todavía se requiere una prueba de conversión real en el navegador y dispositivo de destino.
